Personal use and limitations

Setup in progress. These informational pages describe a personal tool. Google authorization for unattended use is not complete. Live monitoring remains disabled.

Purpose

This is a personal utility operated by John Rizzo to check his own project-delivery audit reports and receive failure notices. It is not a paid service or a public authorization portal.

What a check establishes

A passing offline test establishes simulated code behavior. A passing controlled alert test establishes that specific test’s path to an inbox. Neither proves that all project work was delivered, that a daily report is authentic and complete, or that future scheduled execution and notification delivery are guaranteed.

Gmail access can expire or be revoked. Providers can delay, block or fail execution and delivery. An independent stopped-watchdog check is still required before relying on unattended monitoring.

Owner control

The owner controls the Google authorization, private repository, permitted recipient, audit scope and schedules. No purchase, subscription, additional recipient or public release of private project records is included in this setup. Live monitoring stays disabled until the owner’s verification requirements are met.
